# no-sauce-releases

Release artifacts and the Dalamud custom plugin repository for **NoSauce**.
Source code lives in a private repository; this repo only holds built
`latest.zip` releases and `pluginmaster.json`, the file Dalamud reads to
list/update the plugin.

## Installing NoSauce

In-game: Dalamud Settings → Experimental → Custom Plugin Repositories → add

```
https://raw.githubusercontent.com/Luna-Salamanca/no-sauce-releases/main/pluginmaster.json
```

Save, then find **NoSauce** in the plugin installer.
